# Remix на Deno

Пример приложения [Remix](https://remix.run/) на [Deno](https://deno.com/).

Remix v2 продолжает развиваться как [React Router](https://reactrouter.com/) в режиме фреймворка,
поэтому пример собран на React Router 8.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Статический сайт — сборка Railpack |
| Одностраничное приложение (SPA) | выключено |
| Путь до директории проекта | `/` |
| Директория сборки | `/build/client` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | `deno task build` |
| Путь проверки состояния | `/` |

Порт указывать не нужно: статический сайт отдаётся на порту 80. Railpack видит `deno.json` и
собирает проект в Deno; команда сборки обязательна — сам Railpack для Deno сборку не запускает.
Задача `build` в `deno.json` запускает `react-router build`. Серверный рендеринг выключен
(`ssr: false` в `react-router.config.ts`), страницы пререндерятся в HTML при сборке, готовые
файлы — в `build/client`. Страница в демо одна, поэтому SPA не нужен — несуществующий адрес
отвечает 404.

В демо нет `deno.lock`: версии пакетов выбираются при сборке по диапазонам из `package.json`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
deno install --allow-scripts

# сборка для продакшн
deno task build
```
